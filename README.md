# AR JDM Showroom (Unity)

An augmented reality (AR) showroom built in **Unity** that showcases JDM vehicles with interactive features. The project demonstrates both **marker-based** and **markerless** AR tracking using **Unity’s XR Interaction Toolkit**.

## Features

- **Two AR Scenes**
  - **Markerless AR** scene for surface-based placement
  - **Marker-based AR** scene using image targets

- **Interactive Vehicle Showroom**
  - Two detailed JDM car models
  - Rotating display platform for vehicle presentation
  - Realistic engine sound effects (SFX)
  - Color customization for vehicle body and wheels via a color picker
  - Interactive doors with open/close functionality

## Tech Stack

- **Engine:** Unity  
- **AR Framework:** Unity XR Interaction Toolkit  
- **Tracking:** Marker-based & Markerless AR  
- **Platform:** Mobile AR (ARCore compatible)
